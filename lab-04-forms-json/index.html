CSE Web Development Workshop

About the Workshop

This workshop is designed for students who want to understand how HTML works in real webpages.

The main goal is to help students build correct and structured pages with confidence.

Topics Covered

Core Topics

  • HTML document structure
  • Text, links, and images
  • Lists, tables, and forms

Learning Sequence

  1. Understand page structure
  2. Create content sections
  3. Build data display with tables
  4. Create user input forms

Detailed Plan

  • Week 1
    1. HTML skeleton
    2. Headings and paragraphs
  • Week 2
    • Lists
    • Tables
    • Forms
